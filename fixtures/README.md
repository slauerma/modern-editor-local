# Synthetic test fixtures

All paper text, review comments, and the bibliography entry in this directory are fictional editor tests. They are not user manuscripts or research citations.

`sample/` supplies the application's prepared review example. `audit-paper/` exercises relative source input, references, bibliography, and graphics. The source includes deliberately invalid review cases for regression coverage.

The graphics used by compile tests are generated by `scripts/generate-compile-fixtures.mjs`, which reads no external artwork. Its PDF is drawn from numeric vector coordinates; its JPEG is encoded from numeric grayscale blocks using an original minimal encoder in the script. Neither graphic contains a document page, photograph, identifying metadata, or embedded text from another source. Run `npm run test:compile` to generate them automatically. Both generated files are ignored by Git.
